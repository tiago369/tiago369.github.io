# ROS 2 Tooling

A few smaller ROS 2 packages and configs built along the way, each solving one specific integration problem:

- **[ros2-serial-fpga](https://github.com/tiago369/ros2-serial-fpga)** — a serial (UART) bridge between ROS 2 topics and an FPGA, with the FPGA-side logic written in VHDL.
- **[dobot-mgc-ros2-pkg](https://github.com/tiago369/dobot-mgc-ros2-pkg)** — a ROS 2 package for controlling the Dobot Magician robotic arm.
- **[fastdds_config_files](https://github.com/tiago369/fastdds_config_files)** — Fast DDS (FastRTPS) configuration files for tuning ROS 2's default middleware.

Each repository has its own README with setup instructions.
