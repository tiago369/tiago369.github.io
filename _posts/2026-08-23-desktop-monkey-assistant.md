# Desktop Monkey Assistant

A Bonzi-Buddy-style animated monkey that lives on the desktop and acts as a real assistant: it idles with natural breathing and gesture animations, and answers typed or spoken questions through a local Ollama model — no cloud APIs, everything runs on-device.

It supports push-to-talk speech input (local speech-to-text via faster-whisper), spoken replies (text-to-speech via espeak), and a small sprite-organizer tool for building new animations. The assistant's persona replies in Portuguese by design, even though the codebase itself is in English.

You can access the GitHub repository [here](https://github.com/tiago369/bonzi-buddy).
